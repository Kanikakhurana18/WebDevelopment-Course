Core Object-Oriented Programming (OOP) Concepts

Object-Oriented Programming is a programming paradigm based on the concept of "objects", which contain data and code.

1. Object
An instance of a Class. It is a real-world entity that has an explicit state (data) and behavior (functions).
2. Class
A user-defined blueprint or prototype from which objects are created. It represents the common set of properties and methods shared by all objects of that type.
3. Encapsulation
The wrapping up of data (variables) and code (methods) together as a single unit. It restricts direct access to some of an object's components, which is crucial for data hiding.
4. Abstraction
The concept of hiding the complex implementation details and showing only the essential features of the object to the user. It reduces complexity and increases efficiency.
5. Inheritance
The mechanism by which one class (child/subclass) acquires the properties and behaviors of another class (parent/superclass). This promotes code reusability.
6. Polymorphism
The ability of a variable, function, or object to take on multiple forms. The most common manifestations are method overloading (compile-time) and method overriding (runtime).
